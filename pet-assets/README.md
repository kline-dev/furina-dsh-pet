# pet-assets 素材说明

| 文件 | 说明 |
| --- | --- |
| `sprite.webp` | petdex 官方原始雪碧图（有损 WebP，1536×1872，9 状态 × 最多 8 帧，帧 192×208） |
| `sprite-clean.png` | 清理后的无损 PNG：alpha 硬二值化 + 反预乘去光晕，插件实际提供的就是这份 |

素材来源：[petdex.dev/pets/furina-2](https://petdex.dev/pets/furina-2)

版权归原画作者所有，仅限个人/学习用途。重新生成清洁版请运行 `python tools/clean_sprite.py`。
